# 电脑端文件查看

在 DSH 对话中选择“文件”页签。点击文件夹进入，用“上一级”或工作区根目录返回；文件行和当前位置旁的复制按钮复制服务端校验后的完整路径。

图片、音频和文本支持页内预览，不自动播放媒体；关闭预览返回目录。无法内嵌展示的文件会明确提示，仍可复制路径。切换聊天或目录会取消旧请求，避免显示上一会话内容。

Windows 本机点击视频文件名时，请求配置的本机播放器打开，另有“页内预览”选项。该行为不修改系统文件关联。启动回执仅表示播放器进程已接受启动，不等同于视频已解码或播放成功。

## 安装配置

启用 `files-host` 并保留同仓库 `plugin` 文件接口；前端以可解析的包名注册，作为原生 conversation.view 页签出现，不替换聊天界面。

播放器路径优先使用 `config.playerPath`，其次 `DSH_VIDEO_PLAYER_PATH`。Windows 默认还会尝试 `%ProgramFiles%/ai-player/AgentPlay/AgentPlay.exe`；未安装或未配置时明确失败。AgentPlay 不随插件分发，安装来源与许可证须另行确认。非 Windows 平台不提供此原生打开能力。

## 访问边界

目录、链接和敏感文件检查由工作区文件接口统一执行。原生视频打开额外要求 Windows 本机来源、根聊天页面及已校验的视频文件，仅以参数数组启动指定程序，禁用 shell，不允许客户端指定可执行文件。

不要公开真实工作区文件、截图、配置或日志。自动化测试使用虚构路径和模拟进程；实际播放器、剪贴板和不同屏幕布局仍需平台验收。
