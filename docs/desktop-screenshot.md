# 电脑截图

Windows 与 macOS 本机 DSH 对话输入框提供一个剪刀入口，也可在 DSH 窗口内按 Ctrl+Shift+X。拖动选择屏幕区域，按 Enter 或“确认”进入图片预览；右键或 Esc 取消框选。

预览支持矩形、箭头、文字、马赛克和撤销。点击“添加到输入框”后，截图作为草稿图片等待用户发送。切换会话会取消尚未完成的截图，不能把图片加到另一条聊天中。

## 维护

- `screenshot-host` 注册桌面对话入口；Windows 由 `plugin/screenshot/RegionCapture.cs` 提供原生框选窗，macOS 调用系统 `screencapture -i -r` 交互式选区。
- 原生组件在首次使用时按需编译到 `plugin/.cache/screenshot/`（Windows 通过系统 .NET Framework 编译 `RegionCapture.cs` 与 `RecognizeText.cs`；macOS 通过 `swiftc` 编译 `RecognizeText.swift`），不需要重新安装桌面应用，也不在源码仓库内跟踪二进制产物。
- 图片仅在用户确认区域后返回；取消不返回图片。截图不写剪贴板，服务不保存整屏图片。
- 移动路由只发本机截图连接票据；图片经独立的 `127.0.0.1` 服务返回。手机中继不能通过公开路由取得屏幕图片。
- 固定窗口状态日志位于 `plugin/.cache/screenshot/status.log`，不包含屏幕文字或像素。

## 2026-10-15 / 2026-10-19 截图文字与编辑增强（Windows + macOS）

截图确认后的预览工具栏支持本机提取文字、一键识别后翻译（中文/英文）、可编辑原文/译文、复制文字、追加文字草稿、复制图片、保存PNG、实心遮挡与重做。沿用单一剪刀入口和原生框选，不改取消语义。

OCR 在 Windows 由 `Windows.Media.Ocr` 处理，在 macOS 由 `Vision.framework`（`VNRecognizeTextRequest`，中英双语）在本机处理；不上传或保存截图。识别输入来自当前合成画布，包含标注/遮挡。英文间隔与明显列间隔保留，紧邻中文字符间自动空格清理；识别仍可能有误，侧栏支持修正。

翻译只发送文字给当前会话的模型，不发送图片、聊天历史或工具；无工具的一次性翻译，不插入聊天轮次、不改当前模型/推理设置。面板标明“仅将文字交给当前模型翻译”。窗口关闭、切会话、编辑图片或原文/语言后取消旧请求，迟到结果丢弃。复制/保存使用编辑后的图片，图片与文字均只加入草稿，用户手动发送。

两项处理均走原有带Origin+随机token的独立127.0.0.1截图服务；公开移动路由只提供连接票据，不能借手机中继获得屏幕或OCR结果。PNG解码、像素/输入/输出限制、超时与取消均验证。

43项不同自动测试通过（前端18、后端/原capture15、OCR10）。真实Windows合成中英图OCR约1.24秒，固定短句真实DeepSeek翻译约2.65秒；时间仅代表这次样本。浏览器以固定图代替取屏，实际走OCR/翻译、遮挡、撤销/重做、PNG下载及文字/图片草稿添加。原生框选未在本轮重新取屏，之前用户确认可用的组件未改动。复制图片/文字代码与浏览器API已接入，未覆盖所有桌面宿主剪贴板权限。

公开源码包含相关自动测试；私人验收截图、日志、配置备份不随发行包提供。
