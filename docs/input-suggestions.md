# 上下文输入建议

2026-10-16 已接入本机 DSH。

- 完成回复且输入框完全为空时，显示灰字建议。电脑 Tab 采用、Esc 忽略；手机/平板点灰字采用。采用只更新草稿，仍需手动发送。
- 输入、附件、录音、待回答事项、运行中的任务不抢占；切会话或异步结果过期时丢弃。手机灰字位于输入框内。
- 后端仅取最近四条用户/最终回答，每条最多1600字符，通过当前会话模型的原生 llm 服务生成，不传工具过程或思考记录，不改变会话模型，不调用工具、不写聊天历史。
- 同一上下文缓存30分钟，最多128条；并发上限2，每分钟最多12次生成，模型超时15秒。生成失败或无适当建议时静默不显示。

## 源码与部署

后端 `plugin/suggestions.js`，路由 `/m/api/suggestions`；移动端 `plugin/www/app.js`；桌面独立 `suggestions-host`。

桌面需在 DSH profile 的 node_modules 中建立 `dsh-suggestions` 到本目录同级 `suggestions-host` 的目录联接，cordis.patch.yml 插入 `id: desktop-input-suggestions; name: dsh-suggestions`。必须使用可解析的包名：绝对 file URL 虽能加载 host，却无法通过客户端的 `<包名>/package.json` 发现前端。
